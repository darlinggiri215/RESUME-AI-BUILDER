# 🤖 Resume AI Builder

Resume AI Builder is a smart full-stack web application that helps users create **professional resumes, analyze ATS compatibility, generate keyword suggestions, and export resumes** as PDF files.

Built using Python, Flask, SQLite, HTML/CSS, and JavaScript, this project combines resume building with AI-powered ATS analysis in a clean and responsive interface.

---

## ✨ Features
- 📄 Create Professional Resumes
- 📤 Upload Existing Resume Files
- 🤖 ATS Compatibility Checker
- 🔍 Smart Keyword Suggestions
- 📑 Export Resume as PDF
- 🔐 User Authentication System
- 📂 Resume File Parsing (PDF/DOCX)

---

## 🛠️ Tech Stack
- Python – Backend Logic
- Flask – Web Framework
- SQLite – Database
- HTML/CSS – Frontend Design
- JavaScript – Interactive Features
- Jinja2 – Template Engine
- ReportLab – PDF Generation
- PyPDF2 / python-docx – Resume Parsing
